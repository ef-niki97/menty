# Тексты интерфейса Menty

- Не используй длинное тире (U+2014) в текстах интерфейса. Перефразируй предложение, используй двоеточие, запятую или скобки по смыслу. Для отсутствующего значения пиши «Не указано», а не тире.
- Если самостоятельный текстовый блок состоит из одного предложения, убирай завершающую точку. Вопросительный и восклицательный знаки сохраняй.
- Если в блоке несколько предложений, сохраняй точки, включая точку в конце последнего предложения.
- Не считай точки в сокращениях, датах, числах, именах файлов и ссылках границами предложений и не удаляй их. Например, «24 окт. 2026 г.» сохраняется целиком.
- Используй русские кавычки «ёлочки» для цитат и названий внутри текста. Кавычки синтаксиса HTML, JavaScript, JSON и атрибутов не меняй.
- Оформляй только тексты продукта. Не переписывай введённые пользователем задачи, заметки, отзывы, имена или ссылки и не применяй автоматическую замену при сохранении либо отображении этих данных.
- Проверяй целый видимый блок, включая подставляемый текст и ссылки. Меняй исходные строки точечно, без глобальной замены точек или кавычек в коде.

Примеры:

- «Договор пока не загружен.» → «Договор пока не загружен»
- `Цель не заполнена — добавьте её через редактирование.` → `Цель не заполнена, добавьте её через «Редактировать»`
- «Отзыва пока нет. Отправьте менти ссылку.» сохраняет обе точки
