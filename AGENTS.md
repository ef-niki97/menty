# Согласование изменений

- После правок оставляй изменения локально и показывай результат для проверки.
- Коммит, push, merge в main и деплой выполняй только по отдельной явной команде пользователя после согласования.
- Не считай просьбу исправить баг или добавить функцию разрешением на публикацию.
- Push в main запускает автоматическое обновление сайта через Cloudflare.
