# Menty — панель ментора

Сайт для ведения учеников: профиль, цели, оценка компетенций с радар-диаграммой, история портфолио и CV.
Пока это личная админка. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Запуск

```bash
# из корня проекта
python3 -m http.server 8770
# открыть http://localhost:8770
```

Вход: `admin@admin` / `1234` (заглушка, см. `js/config.js` и `js/auth.js`).

## Экраны

| Путь | Что там |
|---|---|
| `#/login` | Вход |
| `#/students` | Список учеников: статистика, поиск, фильтры по грейду и статусу |
| `#/students/new` | Добавление: профиль → цели → компетенции (+ личная заметка) → итог с диаграммой → «Создать» |
| `#/student/:id` | Карточка: радар «было/стало», история оценок, цель, портфолио и CV с историей версий, задачи, встречи, личная заметка |
| `#/student/:id/assess` | Новая оценка — значения подставляются из прошлой, прежняя показывается пунктиром |

## Структура

```
index.html
css/tokens.css      цвета, радиусы, тени (брендовый цвет — чёрный, переменная --ink)
css/app.css         все стили
js/config.js        учётка, грейды, статусы, список компетенций  ← правится здесь
js/store.js         данные: localStorage + IndexedDB (файлы CV)  ← единственное место работы с данными
js/auth.js          вход (заглушка)
js/metrics.js       средние и динамика
js/radar.js         SVG-диаграмма
js/skills-editor.js редактор оценок (общий для создания и переоценки)
js/views/*          экраны
js/demo.js          демо-ученики (кнопка на пустом экране)
```

## Где лежат данные

Сейчас всё хранится в браузере (карточки — `localStorage`, файлы CV — `IndexedDB`), на этой машине и в этом браузере.
Очистка данных сайта сотрёт и учеников. Резервная копия: меню профиля → «Скачать резервную копию»
(JSON; файлы CV в неё **не входят**).

## Путь к платформе с учениками

- Все чтения и записи идут через `js/store.js`, а вход — через `js/auth.js`; для бэкенда заменяются только они.
- Модель ученика уже содержит `assessments[]`, `portfolios[]`, `cvs[]` — это история, ничего не перезаписывается.
- Личные заметки (`privateNote`) нужно будет отделять от данных, которые видит сам ученик.
- Список навыков — в `SKILLS` (`js/config.js`), диаграмма и редакторы подстраиваются автоматически.
