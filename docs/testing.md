# Проверки перед публикацией

Запуск: `npm test` (Node.js 22.13 или новее с `node:sqlite`).

Тесты выполняются без сети и рабочей базы. SQL проверяется на схеме миграции в SQLite в памяти; D1 и R2 представлены тестовыми адаптерами. OAuth использует подставленные ответы провайдера.

Покрытие:

- Сессии, выход, CRUD учеников и воркспейсов, изоляция аккаунтов
- Файлы: загрузка, чтение, запрет чужого доступа, очистка при удалении ученика
- Публичные ссылки, скрытие разделов и истории, отзыв и самооценка
- Защита ответа менти от устаревшего сохранения ментора
- Импорт, повреждённые документы, совместимость демо-данных и старых статусов
- Независимые статус менторства и результат
- Даты в разных часовых поясах и дробные средние оценки
- Обновление самооценок при заполненной истории из 20 записей
- Диагностика OAuth, ошибки, сохранение cookie и отсутствие приватных данных в метриках

Вручную в локальном браузере проверены поиск и очистка, фильтры, сортировка, список и карточки, меню, мастер создания ученика, редактирование профиля и задачи, отметка задачи, сохранение заметки, ошибка пустой заметки, переход к переоценке и отправка отзыва.

Проверка сборки: `npx wrangler deploy --dry-run`. Перед push также запускается `git diff --check` и проверка синтаксиса JavaScript.

Эти проверки не заменяют реальный вход через Google на рабочем сайте: для исследования задержки после возврата см. [Диагностика авторизации](auth-diagnostics.md).
